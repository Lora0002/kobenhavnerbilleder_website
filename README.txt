# Københavnerbilleder – onepager

## Sådan bruger du siden

1. Åbn mappen i VS Code.
2. Læg alle dine billeder i mappen `images`.
3. Åbn `index.html` i browseren eller brug Live Server.

Strukturen skal være:

kobenhavnerbilleder_website/
├── index.html
├── style.css
├── script.js
└── images/
    ├── kobenhavnerbilleder-sten-simons.jpg
    ├── kobenhavnerbilleder_oppefra.jpg
    ├── kobenhavnerbilleder_aaben_venstre.jpg
    ├── sten_simons.jpg
    └── resten af billederne...

Designet er lavet som en responsiv onepager og følger layoutet fra referencebilledet:
- blågrå hero
- råhvide/olivenfarvede tekstbokse
- bogbilleder
- anmeldelser
- accordion til kapitler
- forfattersektion
- masonry-galleri
- køb-sektion
- mobilmenu

Køb-knappen og prøvekapitel-formularen er lavet som demo. Indsæt selv det rigtige link/formular, når du har det.
